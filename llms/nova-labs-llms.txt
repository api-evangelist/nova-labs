# Nova Labs (Helium)

> Nova Labs, Inc. is the company behind the Helium Network, a decentralized wireless network of community-hosted Hotspots coordinated on Solana and incentivized with the HNT token. Helium runs a global LoRaWAN network for IoT and a cellular/Wi-Fi offload network for mobile connectivity (Helium Mobile). The network's protocol surface is published as open-source gRPC/Protobuf service definitions, alongside first-party client libraries, a CLI, and Rust crates. This llms.txt was generated by the API Evangelist enrichment pipeline from Nova Labs' public developer surface.

## Overview
- Company: Nova Labs, Inc.
- Networks: Helium IoT (LoRaWAN), Helium Mobile (cellular/Wi-Fi offload)
- Backer surfaced from: a16z portfolio
- Primary interface: gRPC/Protobuf (helium/proto). Legacy Helium IoT REST API tooling is archived post-Solana migration.
